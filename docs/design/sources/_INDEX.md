# Catalogue des sources design

Une ligne par vidéo/source ingérée. Chaque source a son fichier d'extraction
`AAAA-MM-JJ_slug.md` dans ce dossier. Les règles tirées de ces sources vivent
dans `../DESIGN_HUMAIN.md`.

**Types de sources acceptés.** La base n'est pas limitée aux vidéos. Une interface
existante consultée au navigateur est une source valide, à condition de distinguer
explicitement ce qui est **mesuré** (CSS calculé sur une app live) de ce qui est
**observé** (capture produit officielle, donc retouchée). Voir la note de méthode en
tête de la fiche du 2026-07-30.
