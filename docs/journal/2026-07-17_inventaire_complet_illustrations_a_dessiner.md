## Charte de style (coller à CHAQUE génération)

Illustration éditoriale au trait, dessinée main, détaillée, style gravure moderne /
presse haut de gamme. Trait fin épaisseur unique + hachures fines pour les ombres.
Encre #1F2A24 (jamais noir pur). UN accent vert émeraude #2E7D5B, uniquement sur
l'élément d'action (sceau/tampon/cadenas). Halo vert diffus #2E7D5B transparent
derrière le sujet. Fond parchemin crème #EDE6D4 grain léger (ou transparent). Centré,
aéré, calme, noble. Zéro texte/logo. Éviter néon, dégradés criards, clip-art, stock,
fond chargé, brillance. Carré 1:1 sauf mention.

## Inventaire (15 pièces, 5 groupes)

**G1 Héros et motif**
1. Nature morte héros : balance + encrier double godet + plume + registre + sceau (vert). Signature page d'accueil.
2. Bandeau d'objets flottants (3:1, fond transparent) : sceau, balance, plume, pièce, registre, maillet. Sceau vert.

**G2 Sections fonctionnalités**
3. Facturation : main sort facture d'enveloppe, tampon vert « payé » se pose.
4. Fidéicommis : coffre entrouvert, 2 piles de billets séparées, cadenas vert fermé.
5. Conformité : balance en équilibre sur registre, petit sceau vert qui veille.
6. Temps et présences : horloge ancienne + feuille de temps + dossiers, coche verte.
7. Mise en ordre (comment ça marche) : adjointe classe dossiers flottants, sceau vert se pose.

**G3 États vides in-app (ton doux)**
8. Aucun client : fauteuil vide + porte entrouverte lumineuse + plante, sceau vert sur bureau.
9. Aucun dossier : classeur ouvert chemises vides alignées + plume, étiquette verte vierge.
10. Aucune facture : carnet de facturation neuf page blanche + plume, ruban vert marque-page.

**G4 Vitrines d'options (4:3, aéré)**
11. Option Temps et présences : tableau d'horaire d'équipe + silhouettes + horloge, coche verte valide la semaine.
12. Option Signature électronique : main + plume, signature manuscrite verte + sceau.
13. Option Dépenses par photo : téléphone photographie reçu → ligne de dépense rangée, coche verte.

**G5 Divers**
14. Erreur/404 : dossier tombé, feuilles ramassées calmement à la main, petit sceau vert intact. Rassurant.
15. Page abonnement (héros sombre, exception) : clé ancienne sur un contrat, tête de clé verte, fond parchemin foncé.

## Usage

Une scène à la fois, charte recollée à chaque fois. Commencer par n°1 (référence de
trait), puis « garde exactement ce style » pour les suivantes. Fond transparent pour
n°2 et objets isolés. Correction type : « Plus épuré, un seul accent vert, plus d'espace
vide, trait plus fin. »
