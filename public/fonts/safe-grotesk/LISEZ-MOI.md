# SAFE Grotesk

Fonte de SAFE Inc., forgee a partir de Geist (Vercel, basement.studio),
sous SIL Open Font License 1.1, sans nom reserve.

Les FORMES sont celles de Geist. Ce qui est propre a SAFE : le nom, le
fichier, le resserrement de 9 unites d'em par cote, et
l'elargissement des traces de 4 %.

L'elargissement arrondit les panses : le « o » passe a un rapport
largeur/hauteur de 0,894, celui de CursorGothic, contre 0,860 avant.
Les blancs lateraux restent plus serres que les leurs.

Regeneration : `node scripts/forger-safe-grotesk.mjs`

Le resserrement vit dans la fonte. Le `letter-spacing` des feuilles doit
en tenir compte, sinon les deux s'additionnent.
